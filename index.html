Implementation Highlights:

  • Based on Baker & Matthews (2004) research
  • Precomputed gradients and Hessian for efficiency
  • Iterative optimization until convergence
  • Works well on textured animals

class InverseCompositionalLucasKanadeTracker:
    def __init__(self, template):
        # Precompute gradients
        self.gradient_x = cv2.Sobel(self.T, cv2.CV_32F, 1, 0)
        self.gradient_y = cv2.Sobel(self.T, cv2.CV_32F, 0, 1)

        # Precompute Hessian inverse
        self.H = self.steepest_descent.T @ self.steepest_descent
        self.H_inverse = np.linalg.inv(self.H)

Performance Metrics

Moderate performance, struggles with similar backgrounds

Challenges Identified:

  • Struggles when animals travel in groups (similar appearances)
  • Confusion with similarly-colored backgrounds
  • Difficulty recovering from occlusions
  • Less robust than correlation filter approaches

Kalman + MOSSE

Smoothed tracking with prediction

Performance

Slight overhead but improved smoothness

Kalman Filter Benefits:

  • Trajectory Smoothing: Reduces jitter in bounding box movement
  • Prediction: Estimates next position based on motion model
  • Occlusion Handling: Maintains tracking during brief failures
  • State Estimation: Tracks position (x, y) and velocity (vx, vy)

Note: Kalman performance is highly dependent on the base tracker quality.

Key Findings

Performance Comparison

  • MOSSE: Best overall with highest accuracy and FPS (60-80 FPS)
  • ICLK: Close second, efficient with precomputation
  • Mean Shift: Limited by color histogram approach, struggles with groups
  • Kalman: Provides 2-5% improvements with smoothing
